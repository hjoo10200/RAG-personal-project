# 청년 자취 독립 자금 계획 계산식

작성일: 2026-08-31

> 후속 변경: 최신 요구사항은 **범주는 선택, 숫자는 직접 입력**입니다. 아래 금액 구간 설명은 구버전 호환용입니다. 현재 비용 기준과 구현은 [비용 기준 수집 및 적용](COST_REFERENCE_RESEARCH_20260831.md), [개편 구현 설명서](RAG_REFACTOR_IMPLEMENTATION.md)를 우선 참고하세요. 정책 검색도 보고서와 별도 기능으로 분리했습니다.

## 1. 목적과 적용 범위

사용자가 선택한 가용 자금·월 수입 구간과 자료에 근거한 예상 비용으로, 어떤 주거 조건을 찾아보고 자금을 어떻게 사용할지 계산하기 위한 문서입니다.

- 범주 정보는 셀렉트, 나이·자금·수입 등 숫자는 직접 입력합니다. 자연어 요청이나 상세 예산표 작성은 요구하지 않습니다.
- 식비·이사비 등은 시스템이 근거 자료에서 확보한 예상값을 사용할 수 있습니다. 계산식 자체가 비용의 적정값을 정해 주는 것은 아닙니다.
- 계산 결과는 입력·추정·가정에 따른 계획 검토값입니다. 독립의 성공이나 실제 매물 확보를 보장하지 않습니다.
- 지원공고의 룰 기반 자격 분류는 범위에서 제외합니다. 지원정책 검색·설명은 기존 RAG 영역으로 남깁니다.
- 이 문서는 계산 정의만 정리합니다. 코드·입력 스키마·출력 payload·대시보드는 구현하지 않습니다.

## 2. 변수 정의

계산은 원 단위를 기본으로 하며, 화면에서는 만 원 단위로 변환할 수 있습니다. 월별 값과 일회성 값을 구분합니다.

| 기호 | 의미 | 기준 |
| --- | --- | --- |
| C | 현재 독립에 사용할 수 있는 가용 자금 | 선택한 금액 구간. 총자산과 구분 |
| D | 앞으로 지급해야 할 보증금 | 이미 지급한 계약금 등은 제외 |
| M | 앞으로 지급할 이사비 | 일회성 예상 비용 |
| B | 앞으로 지급할 중개보수 | 해당 주거 조건의 예상 비용. 세금 포함 여부 표시 |
| F | 앞으로 지급할 초기 구입·설치비 | 가구·가전·생활용품·설치비 등 필요한 항목 |
| U | 입주 준비비 합계 | M + B + F |
| R | 입주 후 별도로 남겨둘 자금 | 계획상의 가정. 용도와 기간 명시 |
| I | 독립 후 월 정기 실수령 수입 | 선택한 상태·금액 구간. 예정 수입은 별도 가정 |
| W | 월세 | 월 지출 |
| G | 관리비 | 월 지출. 포함 항목 확인 |
| L | 주거비 외 월 생활비 | 식비·교통비·공과금·통신비 등의 예상 합계 |
| E | 기존 월 필수 지출 | 대출 상환·가족 지원 등. 다른 항목과 중복 제외 |
| S | 매달 남길 목표 금액 | 저축·추가 적립 등 계획상의 가정 |

R과 S는 임의의 공식 합격선이 아닙니다. 시스템이 제안한다면 왜 그 가정을 사용했는지 설명하고, 가정이 달라질 때 결과도 달라짐을 표시합니다.

## 3. 입주에 필요한 자금과 잔액

```text
입주 준비비 U = M + B + F

초기 필요 자금 = D + U

입주 후 남는 자금 = C − D − U

초기 부족액 = max(0, D + U − C)
```

### 해석

- 보증금은 소비되는 생활비와 구분하지만 입주 시 필요한 현금에 포함합니다.
- 입주 후 잔액이 양수라고 충분한 비상자금이 확보됐다는 뜻은 아닙니다. 이후 생활비와 남겨둘 자금을 함께 검토합니다.
- C, D, U는 동일한 기준 시점으로 맞춥니다. 현재 현금에서 이미 빠진 계약금·준비비를 다시 차감하지 않습니다.
- 첫 달 월세를 입주 당일 지급한다면 별도 지급 항목으로 기록합니다. 기간 전체 현금흐름에서는 월 지출과 중복 차감하지 않습니다.
- 누락된 초기 비용이 있으면 ‘확인된 항목의 소계’로 표시하며 전체 필요 자금으로 확정하지 않습니다.

## 4. 독립 후 월 지출과 잔액

```text
월 주거비 H = W + G

월 지출 T = H + L + E

월 잔액 N = I − T

월 적자액 Q = max(0, T − I)

목표 적립 후 잔액 = N − S
```

### 해석

- N이 양수이면 계산에 포함한 항목 기준으로 매달 남는 금액입니다. 빠진 지출이 있다면 실제 여유 금액으로 확정하지 않습니다.
- N이 음수이면 같은 수입·지출이 유지될 때 보유 자금을 매달 그만큼 사용하게 됩니다.
- S는 소비 지출에 포함하지 않고 별도로 비교합니다. 이미 지출 합계에 넣은 적립액을 다시 차감하지 않습니다.
- 관리비에 수도·인터넷 등이 포함되면 L에서 해당 부분을 제외합니다.
- 전체 생활비 통계에 주거비가 포함되어 있다면 통계 총액에 W와 G를 그대로 추가하지 않습니다.

## 5. 가진 돈으로 찾아볼 주거 조건 역산

### 5.1 보증금에 배정 가능한 금액

```text
보증금 배정 상한 = C − U − R

후보 조건 검토 잔액 = C − D − U − R
```

후보 조건 검토 잔액이 0 이상이면 해당 가정에서 입주 비용과 R을 함께 확보할 수 있습니다. 음수이면 그 절댓값만큼 부족합니다.

보증금에 따라 중개보수 B가 달라질 수 있으므로 U를 항상 고정된 값으로 취급하지 않습니다. 이런 경우 보증금·월세 후보 조합별로 비용을 계산하고 다음 조건을 확인합니다.

```text
D + U(D, W, 기타 주거 조건) + R ≤ C
```

이는 비용 간 의존성을 표현한 식입니다. 특정 지역의 중개보수 요율을 새로 정의하는 것은 아닙니다.

### 5.2 월 주거비에 배정 가능한 금액

```text
월 주거비 배정 상한 = I − L − E − S

후보 조건 검토 = W + G ≤ 월 주거비 배정 상한
```

### 공통 주의사항

- 초기 자금 조건과 월 유지비 조건을 함께 검토합니다. 둘 중 하나만 맞는다고 전체 계획이 성립하는 것은 아닙니다.
- 계산 상한이 음수이면 해당 가정의 부족액을 표시합니다. 0원으로 바꿔 가능한 계획처럼 제시하지 않습니다.
- 이 상한은 자금 기준의 탐색 조건입니다. 해당 가격의 집이 현재 시장에 존재한다는 증거가 아닙니다.
- 실제 자료의 보증금·월세 조합을 유지합니다. 서로 다른 거래의 낮은 금액만 골라 가상의 조합을 만들지 않습니다.
- R에 예정된 소득 공백의 생활비를 배정했다면, 같은 돈을 다른 예비금 항목에도 중복 배정하지 않습니다.

## 6. 월 적자가 발생할 때 예상 유지 기간: 선택 계산

이 계산에서는 별도로 보존할 예비금과 적자를 메우는 데 사용할 자금을 구분합니다.

```text
생활에 사용할 수 있는 잔여 자금 V
  = 입주 후 남는 자금 − 별도로 보존할 예비금

예상 유지 기간(개월) = V ÷ Q
```

### 계산 조건

- V가 양수이고 월 적자액 Q가 양수일 때만 나눗셈을 적용합니다.
- V가 0이면 별도 예비금을 쓰지 않고 적자를 충당할 잔여 자금이 없는 상태입니다.
- V가 음수이면 초기 자금 또는 예비금 목표가 이미 부족하므로 유지 기간 대신 부족액을 표시합니다.
- Q가 0이면 적자 기준 유지 기간은 산출하지 않습니다. ‘무한 유지 가능’으로 표시하지 않습니다.
- 매달 동일한 수입과 지출이 발생한다는 단순 가정입니다. 지출일·급여일 차이, 비정기 비용, 소득 변동은 별도 확인이 필요합니다.
- 수입 ‘없음’은 I = 0으로 계산할 수 있지만, ‘모름’은 0과 다릅니다. 수입 발생 예정 상태도 확정 수입처럼 기본 계산에 더하지 않습니다.

## 7. 셀렉트 금액 구간 처리

예를 들어 사용자가 ‘가용 자금 1,000만 원 이상~1,500만 원 미만’을 선택했다면, 이를 실제 자금 1,250만 원으로 바꾸지 않습니다.

1. 선택 구간의 하한·상한과 경계 포함 여부를 보존합니다.
2. 구간을 사용해 계산 가능한 범위를 제시하거나, 명시적인 시나리오별 결과를 계산합니다.
3. 대표값을 사용하면 사용자의 실제 금액이 아니라 계산용 가정임을 표시합니다.
4. 상한 없는 구간에는 임의의 최대값을 만들지 않습니다. 전체 결과 범위를 정할 수 없다면 계산 가능한 경계 또는 조건부 결과만 제시합니다.
5. 비용 간 관계를 유지합니다. 보증금·월세·중개보수의 서로 맞지 않는 극값을 결합하지 않습니다.

독립된 유한 범위의 보수적인 경계 계산은 다음과 같습니다. 실제 결과에서는 원래의 경계 포함 여부를 유지합니다.

```text
입주 후 잔액의 하한 경계 = C의 하한 − 초기 필요 자금의 상한
입주 후 잔액의 상한 경계 = C의 상한 − 초기 필요 자금의 하한

월 잔액의 하한 경계 = I의 하한 − T의 상한
월 잔액의 상한 경계 = I의 상한 − T의 하한
```

서로 의존하는 비용에는 단순 경계 결합 대신 일관된 후보 조합별 계산을 사용합니다. 계산 범위를 확률적 신뢰구간으로 표현하지 않으며, 평균값 하나에 임의의 비율을 붙여 범위를 만들지 않습니다.

## 8. 누락·추정·중복 처리 원칙

| 상태 | 처리 |
| --- | --- |
| 사용자가 선택한 금액 구간 | 해당 구간으로 유지 |
| 실제로 없음 | 0원 처리 가능 |
| 모름 또는 미입력 | 0원으로 대체하지 않음 |
| 근거 있는 예상 비용 | 자료 시점·적용 조건·포함 항목을 기록해 가정으로 사용 |
| 일부 비용의 근거가 없음 | 부분 계산으로 표시하고 전체 잔액을 확정하지 않음 |
| 미확정 정책 지원금·대출 | 기본 가용 자금·수입에서 제외 |
| 지원·대출을 가정하는 비교 | 별도 시나리오로 분리하고 상환·지급 시점도 고려 |
| 이미 지급했거나 다른 항목에 포함된 비용 | 중복 차감·합산하지 않음 |

계산기는 숫자를 정확히 처리하는 역할입니다. 입력과 비용 가정이 불확실하면 산술이 정확해도 결과가 확정적인 재정 판단이 되는 것은 아닙니다.

## 9. 설명용 산술 예시

아래 금액은 수식 확인만을 위한 가상 시나리오입니다. 실제 시세나 생활비 권장값이 아니며, 셀렉트 구간의 기본값으로 사용하지 않습니다. 단위는 만 원입니다.

| 변수 | 가정값 |
| --- | ---: |
| C: 가용 자금 | 1,000 |
| D: 미지급 보증금 | 500 |
| U: 입주 준비비 | 100 |
| R: 별도로 남겨둘 자금 | 200 |
| I: 월 실수령 수입 | 220 |
| W + G: 월 주거비 | 70 |
| L: 주거비 외 월 생활비 | 80 |
| E: 기존 월 필수 지출 | 20 |
| S: 매달 남길 목표 금액 | 20 |

```text
초기 필요 자금 = 500 + 100 = 600만 원
입주 후 남는 자금 = 1,000 − 600 = 400만 원
초기 부족액 = max(0, 600 − 1,000) = 0원
후보 조건 검토 잔액 = 1,000 − 500 − 100 − 200 = 200만 원

월 지출 = 70 + 80 + 20 = 170만 원
월 잔액 = 220 − 170 = 50만 원
목표 적립 후 잔액 = 50 − 20 = 30만 원
월 주거비 배정 상한 = 220 − 80 − 20 − 20 = 100만 원
```

이 예시가 보여주는 것은 제시한 가정끼리 수치가 맞는다는 사실뿐입니다. 주거비 상한 100만 원을 실제 권장 월세로 제시하거나, 모든 사용자에게 이 배분을 적용하지 않습니다.

## 10. 우선 사용할 계산 결과

우선 범위는 다음 네 가지입니다.

1. 초기 필요 자금과 초기 부족액.
2. 입주 후 남는 자금.
3. 예상 월 지출·월 잔액.
4. 가정에 따른 보증금·월 주거비 탐색 조건.

유지 기간은 적용 조건을 만족할 때만 추가합니다. 각 결과에는 사용한 입력 구간, 추정 비용, 가정, 누락 항목을 함께 남깁니다. 지원공고 조건 분류나 독립 적합도 점수는 이 계산 문서에 포함하지 않습니다.

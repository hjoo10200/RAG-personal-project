# 독립 비용 기준 수집 및 적용

자료 확인일: 2026-08-31. 코드 실행·RAG 실행·재적재는 이 문서 작성 범위에 포함하지 않습니다.

## 적용한 기준표

| 비용·계산 | 채택한 기준 | 실제 처리 |
| --- | --- | --- |
| 주거·수도·광열 외 월 생활비 | 전국 전 연령 1인가구의 2024년 소비 통계 | 약 1,378,000원을 **참고 시나리오**로 사용 |
| 월 주거비 탐색 잔여액 | 실수령 수입 − 위 생활비 − 기존 필수지출 − 입력한 목표 적립액 | 월세·관리비·수도·전기·가스 전체를 비교하는 금액 |
| 중개보수 | 서울시 일반 주택 임대차 요율표 | 지역·건물 유형·보증금·월세가 맞을 때 부가세 별도 상한 계산 |
| 보증금·월세·관리비 | 실제 후보 주택의 조건 | 확인한 숫자가 있으면 입력. 지역 평균을 가상 매물로 만들지 않음 |
| 이사비 | 거리·물량·작업조건별 업체 견적 | 받은 견적 입력. 정액 표준비용을 만들지 않음 |
| 초기 구입·설치비 | 실제 필요한 품목의 총액 | 선택 입력. 풀옵션 여부 등을 모르므로 임의 금액 미적용 |
| 예비금·월 저축 목표 | 사용자 계획 | 선택 입력. 정부가 정한 합격선처럼 고정하지 않음 |

숫자는 직접 입력합니다. 빈칸은 `null`이고 없음은 `0`입니다. 숫자를 구간으로 바꾸거나 중간값으로 대체하지 않습니다. 사용자가 상세 예산을 전부 알아야 하는 구조가 아니라, 기본 자금만으로 먼저 탐색 조건을 얻고 알아본 값으로 보완하는 구조입니다.

## 1. 월 생활비 기준

[국가데이터처 「2025 통계로 보는 1인가구」](https://www.mods.go.kr/board.es?act=view&bid=10820&list_no=442130&mid=a10301010000)의 소비지출 요약(본문 24쪽 안내)을 사용했습니다. 발표일은 2025-12-09, 소비 기준연도는 2024년입니다.

- 월평균 소비지출: 1,689,000원.
- 주거·수도·광열 비중: 18.4%.
- 그 밖의 소비에 대한 파생 참고값: `1,689,000 × (1 − 0.184) = 1,378,224원`.
- 공표 비중에 반올림이 포함되어 있으므로 천 원 단위로 반올림한 **약 1,378,000원**을 저장했습니다.

이는 최소 생활비, 청년만의 평균, 서울 시세, 2026년 가격이 아닙니다. 지역별 배율·물가상승률을 임의로 붙이지 않았습니다. 전국 통계를 지역별 데이터인 것처럼 복제하지 않고 지역 `*`의 공통 참고값으로 등록했습니다. 2인 이상 가구에는 곱해서 적용하지 않습니다.

식비·교통·통신·의료·여가 등 소비를 포함하므로 같은 비용을 기존 필수지출에 다시 넣지 않아야 합니다. `existing_fixed_cost_krw`는 부채상환·가족지원 등 중복되지 않는 별도 지출입니다. 세후 소득에서 이미 공제한 세금·보험료도 재차 빼지 않습니다.

통계에서 주거·수도·광열을 통째로 뺐으므로 실제 월 지출을 계산할 때는 **월세 + 관리비 + 관리비에 포함되지 않은 수도·전기·가스**를 확인해야 합니다. 통신비는 참고 생활비에 포함됩니다.

## 2. 기본 입력으로 나오는 결과

예시 입력은 현금 1,000만 원, 월 실수령 220만 원, 별도 필수지출 10만 원입니다.

```text
주거·수도·광열 탐색 잔여액
= 2,200,000 − 1,378,000 − 100,000
= 722,000원/월 (목표 저축액 미입력: 저축 전)
```

위 값은 수식 설명이며 실제 실행 결과가 아닙니다. **월세 72만 2천 원을 권장한다는 뜻이 아닙니다.** 월세·관리비·별도 공과금이 이 잔여액 안에 들어오는지 검토하는 출발점입니다. 실제 생활비가 통계와 다르면 조건도 달라집니다.

사용자가 `nonhousing_living_cost_krw`를 적으면 이 통계값을 **대체**합니다. 합산하지 않습니다. 월세·관리비·공과금이 없으면 월 전체 잔액은 정보 부족 상태로 남지만, 위 탐색 잔여액은 별도로 제공할 수 있습니다.

## 3. 중개보수 기준

[서울부동산정보광장 중개보수 안내](https://land.seoul.go.kr/land/broker/brokerageCommission.do)를 수집했습니다. 일반 주택의 임대차 상한은 다음과 같습니다.

| 환산 거래금액 | 상한요율 | 금액 한도 |
| --- | --- | --- |
| 5천만 원 미만 | 0.5% | 20만 원 |
| 5천만 원 이상~1억 원 미만 | 0.4% | 30만 원 |
| 1억 원 이상~6억 원 미만 | 0.3% | 없음 |
| 6억 원 이상~12억 원 미만 | 0.4% | 없음 |
| 12억 원 이상~15억 원 미만 | 0.5% | 없음 |
| 15억 원 이상 | 0.6% | 없음 |

월세의 환산 거래금액은 보증금에 월세 100개월분을 더합니다. 그 값이 5천만 원 미만이면 70개월분을 더한 값으로 다시 계산합니다. 전세는 보증금입니다. 요율과 금액 한도를 함께 적용합니다.

현재 자동 계산 범위는 **서울 + 일반 주택 + 월세/전세**입니다. 오피스텔·기타 부동산·다른 지역에는 자동 적용하지 않습니다. 협의 금액은 상한보다 낮을 수 있고, 안내상 부가세는 별도입니다. 따라서 `brokerage_ceiling_excluding_vat_krw`를 실제 초기비용에 자동 합산하지 않습니다. 초기비용에는 사용자가 확인한 세금 포함 총액 `brokerage_cost_krw`를 사용합니다.

## 4. 이사·초기비용을 임의로 채우지 않는 이유

[찾기쉬운 생활법령정보의 이사업체 정하기](https://www.easylaw.go.kr/CSP/CnpClsMainBtr.laf?ccfNo=3&cciNo=2&cnpClsNo=1&csmSeq=666&popMenu=ov)는 물량·거리·작업 여건·날짜 등에 따라 가격이 달라지므로 업체 견적을 비교하도록 안내합니다. 이 원칙을 비용 기준으로 채택했습니다. 지원정책의 최대 지원액을 실제 이사비 평균으로 바꾸지 않습니다.

가구·가전도 이미 가진 물건, 매물 옵션, 중고 구입 여부를 모르면 합리적인 단일 표준가를 정하기 어렵습니다. 이런 비용은 `null`로 남겨 두되 보고서에서 견적과 필요한 품목을 확보하는 순서를 설명합니다. 누락된 초기비용이 있으면 현재 현금 전액을 보증금 상한으로 제시하지 않습니다.

## 5. 검토했지만 자동 비용으로 채택하지 않은 자료

[국무조정실 2024년 청년의 삶 실태조사 발표자료](https://www.opm.go.kr/doc/_attach/file/2025/03/DHqkrnLbagZNXnJoFvkK.hwpx.files/Sections1.html)는 청년가구 평균 생활비와 주택 임대료 통계를 제공합니다. 그러나 청년가구 전체와 자취 1인은 모집단이 같지 않습니다. 보증금 평균과 월세 평균도 사용자가 실제 구할 수 있는 하나의 매물 조건으로 취급하지 않았습니다.

공공임대의 낮은 보증금도 입주자 선정과 특정 공고·주택 조건을 전제로 하므로 일반 독립 비용의 기본값으로 넣지 않았습니다. 지원금·미승인 대출도 가용 현금에 더하지 않습니다.

## 6. 파일과 갱신 방식

- `knowledge_base/metadata/cost_references.json`: 통계 참고값, 계산 근거, 대상 가구, 출처·기준연도·확인일.
- `knowledge_base/metadata/brokerage_reference.json`: 서울 주택 임대차 요율과 원문 링크.
- `src/finance/calculator.py`: 적용 조건 확인 후 계산과 검색용 상황 힌트 생성.
- `src/finance/brokerage.py`: 중개보수 상한 계산.

각 자료의 재확인 기한은 프로젝트 운영상의 기한이며 공식 통계나 법령의 유효기간이 아닙니다. 현재는 수동 검토·갱신 방식입니다. 자동 크롤러나 자동 최신화는 구현하지 않았습니다. 기한이 지나거나 적용 대상이 다르면 해당 기준을 적용하지 않습니다. 새 통계가 발표되면 모집단·포함 항목·기준연도를 확인한 뒤 기준표를 교체해야 합니다.

수집 결과는 재사용 가능한 JSON 기준표와 이 출처 설명서에 정리했습니다. 원문 HTML 전체나 PDF 전체를 저장·적재한 것은 아닙니다. 기존 RAG 문서의 재임베딩은 하지 않았습니다.
